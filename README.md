# Optimizador de rutas de reparto

Herramienta web gratuita para planificar rutas de reparto o visitas: reparte las paradas entre varios vehículos minimizando el costo total (km, conductor por hora, peajes), con tráfico por hora que tú calibras, ventanas horarias de clientes, flota con vehículos distintos, equilibrio de jornada, hora de salida elegida o calculada, rutas sobre las calles reales y un cálculo de flete (borrador).

- Funciona en el navegador de cualquier dispositivo y se puede instalar en el teléfono (Agregar a pantalla de inicio).
- No hay servidor ni cuenta: tus datos se quedan en tu dispositivo.
- Búsqueda de direcciones y calles reales usan servicios públicos de OpenStreetMap (Nominatim, OSRM) con uso justo.
- Es un método heurístico: no garantiza el óptimo. No usa tráfico en vivo. Las tarifas de peaje y los costos los pones tú.
